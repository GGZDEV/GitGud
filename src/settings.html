Moteur

Connexion : lance codex login une fois dans un terminal. Modèle vide = celui par défaut de Codex.
Connexion : lance claude dans un terminal puis /login. Consomme les crédits « Agent SDK » de ton abonnement.

Vitesse

« C'est quoi cet objet ? », « faiblesse de ce boss ? » : premier mot en 1 à 2 s. Les analyses (build, stratégie, méta, patch, comparaison) gardent le moteur complet. La réponse est lue phrase par phrase dès qu'elle arrive.
Vide = le modèle que Codex présente comme rapide (ex. gpt-6-luna) : ~3 s au lieu de ~10 s.

Vision.

La fenêtre que GitGud regarde quand tu poses une question. L'overlay n'apparaît jamais sur la capture.

Capture

Lance ton jeu en mode « fenêtré sans bordure » pour que l'overlay s'affiche par-dessus.
Les repères restent 12 s ; le raccourci « Fermer » les efface.

Overlay.

L'apparence de la fenêtre affichée par-dessus le jeu. Pour la déplacer, tire son en-tête : sa position est mémorisée.

Actions

Jeux.

GitGud reconnaît automatiquement les jeux qui ont un module : Deadlock et Diablo IV en profondeur, les autres grâce aux modules JSON ci-dessous.

Deadlock

Statistiques en direct (méta, counters, objets) via deadlock-api.com.
Pour « analyse mes dernières parties ». Visible sur ton profil Steam ou sur statlocker.gg ; ton historique doit être public dans Deadlock.

Diablo IV

Recherche orientée vers Maxroll, D4Builds et les notes de patch, avec sources citées. Builds (Mobalytics, Maxroll, D4Builds ou le tien), priorités, équipement et scan ont leur propre fenêtre.

Modules de jeu

Un fichier JSON suffit pour ajouter un jeu : reconnaissance de la fenêtre, consignes, sites de référence, vocabulaire, minuteurs prêts à l'emploi, données en direct. Le format est décrit dans le fichier LISEZ-MOI du dossier.

Mémoire.

Ce que GitGud retient de toi d'une session à l'autre : objectifs, progression, difficultés qui reviennent, préférences. Tout reste sur ce PC.

Réglage

L'IA note un fait quand tu en parles (« je vise le niveau 100 », « je meurs toujours contre ce boss »). Tu peux aussi lui dire « souviens-toi que… » ou « oublie que… ».
